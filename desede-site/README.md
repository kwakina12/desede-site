# de Sede — Website Redesign Concept (Portfolio)

A responsive redesign concept of the de Sede (Swiss leather furniture) website, made as a **personal, non-commercial UX/UI portfolio project**.

- Pages: Main · Products (Sofas & Loungers) · Room Concept (Showroom) · Service · About Us
- Responsive: desktop (1920) · tablet (≤1024) · mobile (≤720)
- Designed and built with Claude Design
